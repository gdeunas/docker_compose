## Запуск проекта

### Подготовка окружения
Создайте файл конфигурации `.env` на основе примера:
```bash
cp .env.example .env
```
*Заполните переменные окружения в созданном файле `.env` перед запуском.*

### 2. Запуск через Docker (Рекомендуется)
Для сборки и запуска всех сервисов в контейнерах выполните:
```bash
docker compose up --build
```
Если вы хотите запустить контейнеры в фоновом режиме, добавьте флаг `-d`: `docker compose up --build -d`.

### 3. Остановка контейнеров
Чтобы остановить и удалить контейнеры, связанные с проектом, используйте:
```bash
docker compose down
```

### 4. Локальный запуск (Альтернативный)
Если вы хотите запустить проект без Docker:
```bash
python manage.py runserver
```
